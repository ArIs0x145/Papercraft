Papercraft 學術論文自動生成系統 - 完整技術報告
================================================================

一、專案概述
----------------
Papercraft 是一個基於 Spring Boot WebFlux 架構的學術論文自動生成平台，採用多AI Agent分工模式，支援APA第七版格式，並透過Server-Sent Events（SSE）技術實現即時流式生成。系統能夠接收用戶輸入的研究主題、參考文件，自動產生高品質的學術論文，並支援Word格式輸出。

核心特色：
- 基於Spring WebFlux的響應式架構
- 多AI Agent專業分工（規劃、撰寫、編輯）
- SSE流式即時回應
- 支援多檔案格式上傳與內容整合
- APA第七版格式標準化輸出

二、系統架構與網路設計

**前端SSE接收：**
```javascript
async function startStreamGeneration(url, formData, streamDiv) {
    const response = await fetch(url, {
        method: 'POST',
        body: formData
    });

    // 使用 ReadableStream 處理流式回應
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
        const { done, value } = await reader.read();
        
        if (done) {
            console.log('流式生成完成');
            break;
        }

        const chunk = decoder.decode(value, { stream: true });
        buffer += chunk;
        
        // 即時更新UI
        streamDiv.textContent = buffer;
        streamDiv.scrollTop = streamDiv.scrollHeight;
    }
}
```

**SSE優勢分析：**
1. **即時性**：用戶可即時看到論文生成進度
2. **減少延遲**：無需等待完整生成才顯示結果
3. **用戶體驗**：提供流暢的互動體驗
4. **資源效率**：相比WebSocket更輕量

### 3.1 Controller層詳解

**PaperGenerationController.java**
```java
@Slf4j
@RestController
@RequestMapping("/api/papers")
@CrossOrigin(origins = "*")
@RequiredArgsConstructor
public class PaperGenerationController {

    private final PaperGenerationService paperGenerationService;
    private final FileProcessingService fileProcessingService;

    @PostMapping(value = "/generate", produces = MediaType.TEXT_PLAIN_VALUE)
    public Flux<String> generatePaper(
            @RequestParam("topic") String topic,
            @RequestParam(value = "type", defaultValue = "研究論文") String type,
            @RequestParam(value = "field", required = false) String field,
            @RequestParam(value = "language", defaultValue = "繁體中文") String language,
            @RequestParam(value = "requirements", required = false) String requirements,
            @RequestParam(value = "files", required = false) List<MultipartFile> files) {
        
        log.info("接收到論文生成請求 - 主題: {}, 文件數量: {}", topic, files != null ? files.size() : 0);
        
        try {
            // 構建請求對象
            PaperRequest paperRequest = new PaperRequest();
            paperRequest.setTopic(topic);
            paperRequest.setType(type);
            paperRequest.setField(field);
            paperRequest.setLanguage(language);
            paperRequest.setRequirements(requirements);
            
            // 條件式處理：有檔案vs無檔案
            if (files != null && !files.isEmpty()) {
                // 處理檔案內容
                FileProcessingResult processingResult = fileProcessingService.processFiles(files);
                
                if (processingResult.getProcessedFiles().isEmpty()) {
                    return Flux.just("錯誤：沒有成功處理的文件，無法生成論文。\n");
                }
                
                // 提取檔案內容
                List<String> fileContents = processingResult.getProcessedFiles().stream()
                    .map(FileProcessingResult.ProcessedFile::getContent)
                    .toList();
                
                return paperGenerationService.generatePaperStream(paperRequest, fileContents);
            } else {
                // 直接生成
                return paperGenerationService.generatePaperStream(paperRequest);
            }
            
        } catch (Exception e) {
            log.error("論文生成失敗", e);
            return Flux.just("錯誤：論文生成失敗 - " + e.getMessage() + "\n");
        }
    }
}
```

**關鍵設計點：**
1. **依賴注入**：使用`@RequiredArgsConstructor`自動注入服務
2. **異常處理**：捕獲異常並返回錯誤訊息流
3. **條件分支**：根據是否有檔案選擇不同處理邏輯
4. **日誌記錄**：完整的請求追蹤日誌

**AI Agent整合範例 - generateOutlineStream**
```java
private Flux<String> generateOutlineStream(PaperRequest request, List<String> fileContents, String conversationId) {
    StringBuilder promptBuilder = new StringBuilder();
    
    // 動態組合prompt
    promptBuilder.append(String.format("""
        你是一位專業的學術規劃專家 (PlannerAgent)，專精於APA第七版格式的學術論文設計。
        請為以下論文需求生成詳細且結構化的大綱：
       
        📚 論文基本信息：
        • 研究主題: %s
        • 論文類型: %s
        • 學術領域: %s
        • 輸出語言: %s
        • 特殊需求: %s
        """,
        request.getTopic(),
        request.getType(),
        request.getField(),
        request.getLanguage(),
        request.getRequirements() != null ? request.getRequirements() : "無特殊需求"
    ));

    // 如果有檔案內容，整合到prompt
    if (fileContents != null && !fileContents.isEmpty()) {
        promptBuilder.append("\n\n📄 參考文件內容分析：\n");
        for (int i = 0; i < fileContents.size(); i++) {
            promptBuilder.append(String.format("=== 文件 %d ===\n%s\n\n", i + 1, fileContents.get(i)));
        }
        promptBuilder.append("**重要指示**: 請深度分析上述文件內容，提取關鍵數據、理論框架、研究發現和論證要點，並系統性地整合到以下大綱結構中。");
    }
    
    // 呼叫AI Agent並返回流式結果
    return plannerAgent
        .prompt()
        .user(promptBuilder.toString())
        .advisors(advisorSpec -> advisorSpec.param("CONVERSATION_ID", conversationId))
        .stream()  // 關鍵：啟用流式模式
        .content();
}
```

**4. SSE流式處理核心**
```javascript
async function startStreamGeneration(url, formData, streamDiv) {
    const response = await fetch(url, {
        method: 'POST',
        body: formData
    });

    if (!response.ok) {
        const errorText = await response.text();
        throw new Error(`請求失敗 (${response.status}): ${errorText}`);
    }

    await processStreamResponse(response, streamDiv);
}

async function processStreamResponse(response, streamDiv) {
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
        const { done, value } = await reader.read();
        
        if (done) {
            console.log('流式生成完成');
            document.getElementById('streamIndicator').style.display = 'none';
            document.getElementById('status').textContent = '✅ 流式生成完成！';
            resetForm();
            break;
        }

        const chunk = decoder.decode(value, { stream: true });
        buffer += chunk;
        
        // 即時更新UI
        streamDiv.textContent = buffer;
        streamDiv.scrollTop = streamDiv.scrollHeight; // 自動滾動
    }
}
```
